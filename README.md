Handwritten Digit Recognition using MNIST

1. Project Overview

Handwritten Digit Recognition is a machine learning project that identifies handwritten digits from images. This project uses the MNIST dataset, which contains grayscale images of handwritten digits from 0 to 9.

A neural network is trained using these images so that it can recognize and predict the digit present in a new image.

The project is developed using Python and TensorFlow/Keras along with NumPy and Matplotlib.

2. Objectives

The main objectives of this project are:

- To understand image-based datasets.
- To work with handwritten digit images.
- To learn basic image preprocessing.
- To train a machine learning classification model.
- To recognize handwritten digits from images.
- To evaluate the accuracy of the trained model.
- To understand the basic working of neural networks.

3. Technologies Used

- Python
- NumPy
- Matplotlib
- TensorFlow
- Keras
- MNIST Dataset

4. Dataset

The project uses the MNIST handwritten digit dataset.

The dataset contains:

- 60,000 training images
- 10,000 testing images
- Image size: 28 × 28 pixels
- Image type: Grayscale
- Classes: 10
- Digits: 0 to 9

The MNIST dataset is automatically downloaded by Keras when the program is executed for the first time.

5. Methodology

The project follows these steps:

1. Load the MNIST dataset.
2. Examine the dimensions of the images and labels.
3. Normalize the pixel values from 0–255 to 0–1.
4. Convert the digit labels into one-hot encoded values.
5. Build a neural network using Keras.
6. Train the model using the training dataset.
7. Evaluate the model using the testing dataset.
8. Predict sample handwritten digits.
9. Compare the actual and predicted values.
10. Display training and validation accuracy.

6. Model Architecture

The neural network consists of the following layers:

- Flatten Layer – Converts the 28 × 28 image into a one-dimensional array.
- Dense Layer – 128 neurons with ReLU activation.
- Dense Layer – 64 neurons with ReLU activation.
- Output Layer – 10 neurons with Softmax activation.

The output layer represents the probability of each digit from 0 to 9.

7. Model Training

The neural network is trained for 5 epochs using the MNIST training dataset.

During training, the model learns patterns and shapes present in handwritten digits. After training, the model is tested using images that were not used during training.

8. Evaluation

The program evaluates the trained model using:

- Test accuracy
- Test loss
- Actual digit values
- Predicted digit values
- Training accuracy
- Validation accuracy

The project also generates:

- "mnist_predictions.png"
- "training_accuracy.png"

These files are generated by the Python program to help analyze the model's predictions and training performance.

10. Installation

Step 1: Install Python

Install Python on your computer and make sure Python is added to the system PATH.

Step 2: Open the Project Folder

Open Command Prompt or Terminal inside the project folder.

Step 3: Install Required Libraries

Run:

pip install -r requirements.txt

11. How to Run the Project

After installing the required libraries, run:

python mnist_digit_recognition.py

The program will automatically download the MNIST dataset if it is not already available.

It will then train the neural network and display the test results and predictions.
